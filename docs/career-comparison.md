# Two career directions compared

| | Direction A: Forward deployed / applied AI engineering | Direction B: AI engineer inside an industry (healthcare) |
|---|---|---|
| Based on which postings | #1 Palantir FDE (entry point), #2 OpenAI Applied AI Engineer (where it leads) | #3 NYU Langone AI Engineer |
| Day-to-day work | Embedded with a customer's team: find the problem, build and ship the fix, often an AI workflow | Build and run AI systems for one organization's own staff and patients, under strict data rules |
| Skills asked for most | A programming language, owning problems end to end, talking with users and leaders, building custom apps, LLM workflows | Python, PyTorch/TensorFlow, LLM deployment and monitoring, cloud, CI/CD, HIPAA and safety |
| Skills I can already show | Python back end with accounts, saved data and a server-side game opponent; tests; Docker; a browser front end ([is218-individual-game](https://github.com/Jefferson2036-droid/is218-individual-game)). Planning and checking work in the open (project record) | Python, Docker, automated tests, documented decisions (same repo) |
| Gaps | Work for a real customer or user; LLM workflows; large datasets; TypeScript/React | PyTorch or TensorFlow; LLM deployment, RAG and monitoring; cloud (Azure/AWS); cluster tools (Spark, Kubernetes); healthcare data rules |
| One project that would show the gap skill | The Group Customer Studio project: a real customer, a shared workflow, and one AI feature built for them, written up as a case study | A small retrieval (RAG) app over public health documents, with an evaluation set and a monitoring dashboard |
| Entry requirements | New grad; graduate Dec 2026 or spring 2027 (#1) | 0–1 years; bachelor's degree (#3) |

## Decision
**Direction the portfolio will lead with:** A, forward deployed engineering.

**Why (pointing at the postings):**
- The new-grad FDE role (#1) asks for one language and proof of owning a problem end to end, not years of experience. My game project already shows end-to-end ownership: research, decisions, back end, front end, tests, and a written record of what was and wasn't checked.
- The Customer Studio group project is the same kind of work as an FDE: a real customer, a bounded problem, a shared workflow. It can become the portfolio's second case study.
- Posting #2 shows the same path continues into senior applied AI work, so the skills compound.

**Direction B stays as a backup.** #3 is open to new grads, but its tool list (PyTorch, cloud, MLOps) is further from what I can show today.
