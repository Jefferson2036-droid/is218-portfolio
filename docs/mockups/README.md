## Design tokens
| Token | Value |
|---|---|
| Text (navy) | `#0B1F3A`; secondary `#33435A`; muted `#4A5A70` |
| Accent (blue) | `#0A58E8`; darker blue for hover `#0848C0` |
| Section background | `#EEF4FF` |
| Rules and borders | `#D5DEEC` (1 px) |
| Status tags | Done/Shown `#E7F6EC` on `#0E5E2D`; In progress/Planned/Learning `#FFF1E0` on `#8A4B00`; Experience/Partial `#EEF4FF` on `#0A3FA8` |
| Headings | Inter 800, tight letter-spacing (-0.03em), sizes 72 / 40 / 26 px on desktop |
| Body | Inter 400–600, 16–19 px |
| Labels | IBM Plex Mono 500, 12–13 px, uppercase |
| Shapes | Square corners, 1 px borders, 4 px blue top/bottom accents, max content width 1200 px |

Known design issues to fix later are listed in [../frontend.md](../frontend.md) (headshot, own copy, font, grid contrast, monogram).
