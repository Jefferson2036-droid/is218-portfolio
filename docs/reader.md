# Reader

- **The one reader this site is for:** A hiring manager or campus recruiter screening new-grad Forward Deployed Engineer applicants, such as for Palantir's posting (#1).
- **What they are trying to decide:** Whether to move me to an interview: can I own a messy problem, build something that works, and explain it to people who aren't engineers?
- **How long they will spend:** About a minute on the home page; a few minutes on one project if the first screen earns it.
- **What they need to see first:** The role I'm aiming for, one finished project with a link to try it, and how I checked that it works.
- **What would make them leave:** A list of class assignments with no story, no way to try anything, broken links, or not being able to tell what I did versus my team.
